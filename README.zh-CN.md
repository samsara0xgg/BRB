# BRB

[English](README.md)

BRB（be right back，马上回来）是把 MacBook 留在图书馆或咖啡馆桌上时用的菜单栏小工具。警戒时每块屏幕都变成磨砂玻璃，上面只有一句话：请勿触碰。路过不会被录下；一旦有人碰它，屏幕从被碰的地方泛红、锁屏、报警，存下碰之前 10 秒和之后的画面，并通知你的手机。

需要 Apple 芯片的 MacBook，macOS 14 或更新。在 macOS 26 上提示牌是液态玻璃（Liquid Glass）。

## 安装

需要 Apple 芯片的 MacBook、macOS 14 或更新，以及 Apple 的命令行工具（还没装的话运行 `xcode-select --install`）。

```sh
git clone https://github.com/samsara0xgg/guard-mode.git
cd guard-mode
./install.sh
```

（也可以点 **Code → Download ZIP**，解压后在那个文件夹里运行 `./install.sh`。）

`install.sh` 会构建 App，马上启动并设为每次登录自动启动，然后问你要不要装一条 sudo 规则（`scripts/sleep-rule.sh`，只需输入一次密码），让警戒时合上盖子电脑也不睡眠。菜单栏会出现一个盾牌，面板会自己打开：

1. **三张卡片**，讲清它做什么、录什么、怎么停下。
2. **静音试一次。** 过程中会请你允许辅助功能（用来发现键盘和触控板被碰）和摄像头；还缺什么，面板会列出来，每一项都有修复按钮。
3. **等屏幕变成磨砂后碰一下触控板**：屏幕会像陌生人碰到时那样泛红并锁屏，只是不出声。解锁或把手指放在触控 ID 上就能停下。测试模式用完会自动关闭。

面板底部的 **使用说明** 可以再看一遍卡片。`./uninstall.sh` 会把它卸掉（包括那条 sudo 规则），录像留在 `~/Movies/BRB/`。日志在 `~/Library/Logs/brb.log`。

## 你会看到什么

- **菜单栏盾牌。** 关闭时是空心轮廓；5 秒倒计时时琥珀色从下往上涨满；警戒中是实心琥珀色；报警时变红并带感叹号；测试模式下有一道斜杠；只有部分在警戒时（没有摄像头，或运动传感器停了）是半满。
- **面板。** 点盾牌打开。可以开始警戒、选地点（图书馆、咖啡馆、路上）、写一句屏幕留言、调警笛音量、开测试模式、开关磨砂屏幕，设置手机提醒和手机页面，打开录像，看最近几次记录。缺什么权限（辅助功能、摄像头、合盖不睡眠的规则），面板会列出来，能修的直接帮你修。
- **倒计时。** 圆环数 5 秒，雾从屏幕中间向外漫开。按 `esc` 取消，手指轻放在指纹键上也能取消。
- **警戒中。** 圆环拉伸成一块玻璃提示牌：“请勿触碰 / 这台电脑正在警戒，碰它会报警”。下面的绿点标签写着“路过不会被录下，碰它才会录像”，旁边是你的留言。底部用另一种语言再说一遍（中文界面下是英文，英文界面下是中文）。其他屏幕只有磨砂和一行小字。
- **报警。** 红色从被碰的地方漫开（触控板是指针处，键盘在屏幕下方，合盖在转轴处，指纹在右下角，电源在左侧），提示牌只说真实发生的事（“画面已录下，机主已收到通知”），然后锁屏。
- **欢迎回来。** 用指纹或解锁后，雾从右下角化开。提示牌告诉你离开了多久、期间发生了什么，然后缩进菜单栏的盾牌里。

## 什么会触发

| | 警笛 |
|---|---|
| 被拿起或带走、倾斜超过 15°、屏幕开合超过 20°、拔掉电源（开始警戒时插着的话）、按电源键 | 立刻响 |
| 按键、点击、碰触控板、不是你的指纹 | 先响 10 秒提示音，留出取消误报的机会 |

敲桌子、旁边放个包、推一下又停住，都不算；欢迎回来时会显示“忽略了几次轻碰”。**咖啡馆** 需要更大、更持久的动作才算。**路上** 不看晃动，只看超过 20° 的倾斜、屏幕开合、电源和触碰。

警戒时音量、静音和亮度键照常能用。按指纹键在系统里就是按电源键，所以电源键会先等 400 毫秒，给指纹解除的机会。

## 隐私

- 从倒计时开始，摄像头只在内存里保留最近 10 秒。没人碰，就什么都不会写到硬盘上。
- 一旦触发，这 10 秒和之后的画面存到 `~/Movies/BRB/`（保留 7 天，最多 20 GB）。
- 录像、照片和手机页面里，除了离镜头最近的那张脸，其他人脸都会打码：碰电脑的人看得清，后面路过的人看不清。
- 手机页面只在报警之后才有画面。

## 手机

- **提醒**（可选）通过 [ntfy](https://ntfy.sh) 推送。在面板里打开，用 ntfy App 扫码订阅，发一条测试。报警时推送发生了什么和一张照片，解除后再推一条。订阅名是唯一的钥匙，ntfy.sh 上的照片保留 3 小时。
- **手机页面** 的链接和二维码在面板里。报警前只显示电脑有没有在警戒；报警后能看实时画面、最多 6 张照片（保留 30 天）和经过。页面只能看，不能控制电脑。报警推送里的链接只在这次报警解除前有效（因为 ntfy 会保存消息）；面板里的链接一直有效。面板里的 **重置链接** 会让旧链接立刻失效，并清掉中继上存的东西。

页面跑在 `relay/` 里的中继上，是一个 Cloudflare Worker，默认用作者部署的那个。想用自己的：运行 `cd relay && npx wrangler deploy`，再运行 `defaults write com.allen.guard-mode relayHost <你的-worker>.workers.dev`，然后重启 BRB。还可以在 Worker 上设置 `CAM_IDS`，只允许列出的房间号连接（面板里手机链接 `/v/` 后面那串）。

## 命令

`build/BRB.app/Contents/MacOS/brb <命令>`：

| 命令 | 作用 | 声音 |
|---|---|---|
| `selftest [--no-hardware]` | 用合成数据测检测器、输入分类、历史记录、图标和文案，再查硬件 | 无声 |
| `sensors [秒]` | 实时显示开合角度、晃动、轻碰次数和触发判断（按面板里选的地点） | 无声 |
| `keys [秒]` | 显示每个真实按键或触控板事件会被怎样处理（终端需要辅助功能权限） | 无声 |
| `camera [秒]` | 像警戒时一样缓存画面，中途像触发一样开始保存 | 无声 |
| `record [秒]` | 把原始加速度和开合角度输出成 CSV，方便离线调参 | 无声 |
| `siren [秒]` | 先响提示音，再响警笛，最后恢复音量 | 很响 |
| `live [秒]` | 打开摄像头并允许实时画面，连上中继，打印机主链接（用 `open -n -W build/BRB.app --args live 60` 才有摄像头权限） | 无声 |
| `push` | 和面板里一样的测试推送，带照片 | 电脑上无声 |
| `snapshot <阶段> [png]` | 显示 `countdown`、`armed`、`test`、`alarm`、`welcome` 各阶段的磨砂屏幕，或 `panel` / `notready` 面板，持续 3.5 秒；加 `-AppleLanguages "(zh-Hans)"` 看中文 | 无声 |

调参的地方：`MotionDetector`（`tiltLimit`、`shakeLimit`、`sustainFraction`），各地点的数值在 `Place`，还有 `LidDetector.limit` 和 `GuardApp.countdownSeconds` / `softSeconds`。

## 语言

英文是基础语言。Swift 源码里的每条文案本身就是英文的键，中文在 `Resources/zh-Hans.lproj/Localizable.strings`；系统语言是中文的 Mac 会显示中文。`scripts/check-strings.py`（CI 里会跑）在有文案没翻译、或参数对不上时报错。

## 开发

`./build.sh` 构建 `build/BRB.app`；`SIGN_IDENTITY=-` 用临时签名。CI（`.github/workflows/build.yml`，macOS 26）会构建、检查 plist 和文案、跑 `selftest --no-hardware`、检查中继语法；只在 PR 和 `main` 上跑。

## 还要在真机上确认的

这些 CI 里测不了：

1. 屏蔽层级（shielding level）上的磨砂真的会模糊后面的桌面（`NSVisualEffectView`，behind-window），倒计时里雾漫开得顺滑。
2. 磨砂窗口在前台时，从倒计时起手指放在指纹键上就能解除。
3. 碰触控板后红色从指针处漫开，1.2 秒后锁屏。
4. 触发后存下的录像从碰之前约 10 秒开始，`kill -9` 之后也能播放。
5. 镜头前有两个人时，录像、照片和手机页面里只有近的那张脸是清楚的。
6. 欢迎回来的提示牌缩进菜单栏的盾牌里。
7. 警戒时屏幕不会自己熄灭，接上第二块屏幕后提示还在。
8. 面板里的留言框能打字，每个“修复”按钮打开的是对的设置页。
9. `npx wrangler deploy` 之后：用面板里的链接打开手机页面；用推送里的链接在解除前后各打开一次。

然后是之前的真机步骤，除了警笛都用测试模式：

1. `keys 30`：音量、静音、亮度键什么都不打印；字母、点击、触控板打印 `TRIGGER`。
2. `sensors 60`：敲桌子不能触发；拿起、带走、倾斜、把屏幕合上一半都要触发。
3. `siren 3`。
4. 开始警戒，碰触控板：屏幕泛红并锁屏，先响提示音，10 秒后响警笛。10 秒内用指纹就能停下，音量恢复原样。
5. 开始警戒，拿起电脑：警笛立刻响。
6. 插着电源开始警戒，拔掉：触发。
7. 开始警戒，触发，`kill -9` 进程：它会重启并继续报警，解锁即可解除。
8. 开始警戒，放一根没录入的手指：触发。
9. 倒计时时把手指放在指纹键上，或按 `esc`：取消。

## 紧急停止

`kill -9` 会让 App 重启并继续报警。`bootout` 发送 SIGTERM，会解除警戒：恢复音量、让电脑能正常睡眠，并且不再启动：

```sh
launchctl bootout gui/$(id -u)/com.allen.guard-mode
```

`./install.sh` 可以再装回来，`./uninstall.sh` 会彻底卸掉。如果合盖后电脑还是不睡，运行 `sudo pmset -a disablesleep 0`。面板里的退出只在没有警戒时可用。
